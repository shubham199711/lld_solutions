# Design Amazon Locker System

Requirements:
-  Multiple locker sizes:
    - SMALL
    - MEDIUM
    - LARGE
- Package has size.
- System assigns smallest available locker that fits package.
- Customer receives pickup code.
- Customer can collect package.
- Locker becomes available again.
- Support multiple locker locations.
- Support package expiration after 3 days.

# Future requirement:
- Refrigerated lockers.
